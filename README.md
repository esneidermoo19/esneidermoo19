## 🚀 Sobre mí
- 🎓 Aprendiz SENA en desarrollo de software.
- 🔭 Actualmente enfocado en el desarrollo full-stack: APIs con FastAPI y Express/TypeScript, interfaces con React y Flutter, y sistemas de gestión (hoteles, granjas) con PostgreSQL, pruebas y CI/CD.
- 🌱 Perfeccionando habilidades en gestión de **Bases de Datos Relacionales (PostgreSQL, SQLite)**.
- 📚 Aprendiendo ahora: **FastAPI, Flutter, testing y CI/CD con GitHub Actions**.
- 💡 Me apasiona construir aplicaciones intuitivas, desde sistemas POS e inventarios hasta plataformas interactivas.
- 🤝 Abierto a colaborar en proyectos de **TU_AREA**.
- ⚡ Dato curioso: **TU_DATO_CURIOSO**.

### 🧱 En qué he trabajado
- 🐔 **Granja Mavic**: sistema web full-stack y PWA de gestión avícola para el control integral de galpones, lotes, producción de huevos, alimento, sanidad y ventas. Construido con Express/TypeScript, Prisma ORM, React/Vite y Tailwind CSS, con soporte para funcionamiento offline.
- 🏨 **Sistema de gestión hotelera (PMS)** con Flask: roles de administrador, recepcionista, empleado y cliente. Migré la base de datos de SQLite a PostgreSQL, lo desplegué con Docker, Gunicorn y Coolify, y documenté historias de usuario y un manual de usuario.
- 🔄 **Hotel_Fast, reescritura del PMS con FastAPI + Flutter**: SQLAlchemy, Alembic, pruebas con Pytest y migraciones verificadas con PostgreSQL en un pipeline de GitHub Actions.
- 🎮 **Juego-millonario**: juego de trivia full-stack inspirado en «¿Quién quiere ser millonario?», con Flask, arquitectura en capas, frontend en HTML/CSS/JS y API REST.
- 🛒 **Treintaclone**: app de punto de venta con Python y KivyMD, inspirada en Treinta, con inventario, ventas y reportes.
- 📚 **Biblioteca_Flask**: sistema de gestión de biblioteca con autenticación, contraseñas con hash, validación de registro y arquitectura con blueprints.
- ☕ **App de escritorio en Java Swing** para gestión de un hotel.
- 🧩 **Extensión de Chrome** para llevar el progreso de lo que veo en Crunchyroll.
- 📝 **Ingeniería de requisitos**: material académico sobre el estándar IEEE 830 / SRS, con presentaciones y guías de estudio.

> 🌎 *EN: Software developer and SENA apprentice focused on web and desktop apps with Python, JavaScript and Java. Open to collaboration and new opportunities.*
